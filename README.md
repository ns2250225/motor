# 鹈鹕暴力摩托 Pelican Road Rage

一款以搞怪鹈鹕为主角的 **3D 摩托车竞速战斗网页游戏**。玩家驾驶造型夸张的摩托车，与 7 名 AI 鹈鹕骑手在赛道上激烈竞速，还能用鹈鹕标志性的大嘴巴、翅膀和各种搞怪道具攻击对手——把对手撞飞、啄翻或者甩出赛道。

游戏采用卡通低多边形（Low Poly）3D 美术风格，强调夸张的物理反馈、搞笑的角色动作、爽快的战斗与简单易上手的操作。支持 **PC 浏览器 + 移动端浏览器（横屏）**，无需下载安装，打开网页即可游玩。

> 需求文档见 [prd.md](prd.md)。

## 特性亮点

- 🐦 **鹈鹕大嘴战斗**：啄击、横扫、嘴巴夹击再甩飞，还有张嘴高速冲撞的超级鹈鹕冲刺
- 🏍️ **3D 暴力竞速**：街机手感驾驶、漂移、氮气冲刺、摩托冲撞与物理碰撞
- 🗺️ **10 条主题赛道**：海岸公路、霓虹都市、沙漠、雪山、雨林、火山、港口、农场、彩虹公路、月球，每条都有隐藏捷径
- 💥 **夸张物理效果**：对手被撞飞、摩托翻滚、鹈鹕羽毛乱飞
- 🎮 **6 种游戏模式**：快速比赛、生涯模式、暴力淘汰赛、计时挑战、无尽公路、疯狂混战
- 📱 **双端适配**：PC 键盘/手柄 + 移动端横屏触控（自动请求横屏）
- 🎨 **零外部资源**：所有模型、贴图、音效和音乐均由代码实时生成

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 前端框架 | Vue 3 + Pinia |
| 开发语言 | TypeScript |
| 构建工具 | Vite |
| 渲染引擎 | Three.js |
| 物理引擎 | Rapier 3D |
| 数据存储 | IndexedDB / localStorage（无需后端） |

## 快速开始

```bash
npm install
npm run dev        # 开发服务器（--host，手机可通过局域网访问）
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览生产构建
```

`dist/` 为纯静态产物，部署到任意静态托管即可。

## 游戏模式

| 模式 | 说明 |
| --- | --- |
| 🏁 快速比赛 | 选择赛道直接与 7 名 AI 竞速 |
| 🏆 生涯模式 | 连续挑战不同赛道，完成特殊挑战赢取三星解锁内容 |
| 🥊 暴力淘汰赛 | 每 25 秒淘汰最后一名，血量被掏空直接出局 |
| ⏱️ 计时挑战 | 无对手，挑战最快圈速 |
| 🛣️ 无尽公路 | 无限延伸的道路，3 条命持续躲避障碍和战斗 |
| 🌪️ 疯狂混战 | 道具刷新更快、攻击冷却减半、伤害更高 |

## 操作说明

### 键盘（PC）

| 键盘 | 功能 | 键盘 | 功能 |
| --- | --- | --- | --- |
| W / ↑ | 加速 | J / K | 左 / 右翅膀拍击 |
| S / ↓ | 刹车 | L | 大嘴啄击 |
| A D / ← → | 转向 | U | 大嘴横扫 |
| Space | 漂移（空中按下＝特技） | I | 大嘴夹击 |
| Shift | 氮气 | Q | 超级鹈鹕冲刺（能量满） |
| E | 使用喉囊道具 | H | 喇叭 |
| R | 复位摩托 | C | 切换镜头 |
| Esc | 暂停 | | |

### 移动端

横屏布局：左手转向按钮（或虚拟摇杆），右手加速/刹车、漂移、攻击（自动选择翅膀/啄击）、大嘴（夹击 > 横扫 > 啄击）、氮气、道具、超级冲刺；默认自动加速。也支持手柄。

## 测试工具

```bash
npm run validate-tracks              # 检查 10 条赛道几何：自交、捷径节省比例与净空
npm run sim -- all quick 260         # 无渲染整场模拟：8 名骑手跑完比赛，输出名次/摔车原因/结算
npm run sim -- coast endless 400     # 模式：quick | career | elimination | timetrial | endless | chaos
```

## 项目结构

```
src/
├── core/       游戏循环（固定 60Hz 物理步长 + 插值渲染）、渲染器（画质分级、动态分辨率）、
│               摄像机、Rapier 物理封装、输入合并、比赛会话
├── entities/   鹈鹕与摩托的程序化低多边形模型及动画、骑手街机物理、AI 控制器、投射物
├── systems/    战斗、漂移、氮气、道具、危险物、竞速/淘汰规则、重生、粒子特效、
│               天气、音效/音乐合成、存档、结算、无尽公路
├── tracks/     数据驱动的赛道配置、样条道路与地面查询、赛道构建器、检查点
├── ai/         AI 性格、路径跟随、超车与避障规划
├── data/       鹈鹕、摩托、装饰、道具、生涯关卡、成就等静态数据
├── stores/     Pinia 全局状态（界面路由、存档、解锁）
├── controls/   键盘、触控与屏幕方向管理
├── ui/         Vue 界面（菜单、模式/赛道/角色选择、车库、图鉴、设置、HUD、小地图、触控、结算）
└── utils/      数学、材质、设备检测、事件工具
```
